
# About this Repository 📌

This repository contains the project I did as a part of the coursework for the module Risk and Decision-Making for Data Science and AI. The assignment consisted of several individual questions using Bayesian Networks, probabilistic models, machine learning to optimise decision-making under uncertainty.


# Key Takeaways 🔍

1. Data Analysis & Probability: Processed tabular student data and learned conditional probability tables (CPTs) to quantify complex stochastic dependencies across variables.
   
2. Bayesian Networks & Probabilistic Reasoning: Modeled multi-variable causal interactions and structural colliders in pyagrum to evaluate conditional independence and d-separation.
 
4. Machine Learning & Parameter Learning: Trained probabilistic graphical parameters directly from empirical data to automate risk assessment and predictive scoring.
 
5. Causal Inference: Analyzed collider paths and backdoor dependencies to isolate true causal drivers of academic outcomes under diverse counterfactual scenarios.
 
6. Decision Optimization: Executed exact inference queries under observed evidence to simulate targeted intervention strategies and quantify outcome probabilities.

# Reflection 🪞 
Working on this Bayesian Network project provided practical insight into how probabilistic graphical models handle uncertainty and complex risk factors in real-world environments. Unlike traditional black-box machine learning algorithms, Bayesian Networks offer full interpretability by explicitly displaying conditional dependencies and causal pathways.

Developing and parameterizing this model highlighted the sensitivity of conditional probability tables to sample size and distribution. Ultimately, the project demonstrated how evidence propagation allows data scientists to simulate counterfactual outcomes and optimize decision-making strategies effectively.
